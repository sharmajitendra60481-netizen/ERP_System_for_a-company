# OilERP - Render Deployment Setup Guide

This document provides complete instructions for deploying the OilERP system to Render.

## ✅ What's Been Fixed

1. **CORS Configuration** - Dynamic origin handling for production deployments
2. **Environment Variables** - Proper support for FRONTEND_URL and NODE_ENV
3. **API Server Binding** - Listens on 0.0.0.0 for containerized environments
4. **Render Configuration** - Updated render.yaml with production settings
5. **Documentation** - Clear deployment instructions

## 🚀 Quick Start Deployment (5 steps)

### Step 1: Prepare Your GitHub Repository
```bash
# Push your code to GitHub
git init
git add .
git commit -m "Initial OilERP commit"
git remote add origin https://github.com/YOUR_USERNAME/your-repo.git
git push -u origin main
```

**Important**: Ensure `.env` is NOT committed (it's in `.gitignore`)

### Step 2: Create PostgreSQL Database on Render
1. Go to [Render Dashboard](https://dashboard.render.com)
2. Click "New" → "PostgreSQL"
3. Choose "Free" tier
4. Name it `oil-erp-db`
5. Copy the "External Database URL" - you'll need this next

### Step 3: Deploy API Service
1. In Render Dashboard, click "New" → "Web Service"
2. Connect your GitHub repository
3. Configure:
   - **Name**: `oilerp-api`
   - **Branch**: `main`
   - **Runtime**: `Node`
   - **Build Command**: `pnpm install --frozen-lockfile && pnpm --filter @oil-erp/database db:generate && pnpm --filter @oil-erp/api build`
   - **Start Command**: `pnpm --filter @oil-erp/api start`
4. Click "Advanced" and add Environment Variables:
   ```
   NODE_VERSION = 22
   NODE_ENV = production
   DATABASE_URL = [paste your PostgreSQL URL from Step 2]
   DIRECT_URL = [paste your PostgreSQL URL from Step 2]
   FRONTEND_URL = [leave blank - will update after web deploy]
   JWT_SECRET = [Render will auto-generate]
   ```
5. Click "Deploy" and wait for completion
6. Once live, verify by visiting: `https://your-api-url.onrender.com/health`

### Step 4: Initialize Database
Run these commands from your local machine:
```bash
export DATABASE_URL="your-postgres-url-from-step-2"
export DIRECT_URL="your-postgres-url-from-step-2"

pnpm --filter @oil-erp/database db:push
pnpm --filter @oil-erp/database db:seed
```

### Step 5: Deploy Web Service
1. In Render Dashboard, click "New" → "Web Service"
2. Use same GitHub repository
3. Configure:
   - **Name**: `oilerp-web`
   - **Branch**: `main`
   - **Runtime**: `Node`
   - **Build Command**: `pnpm install --frozen-lockfile && pnpm --filter web build`
   - **Start Command**: `pnpm --filter web start`
4. Click "Advanced" and add Environment Variables:
   ```
   NODE_VERSION = 22
   NODE_ENV = production
   NEXT_PUBLIC_API_URL = /api
   API_URL = https://oilerp-api.onrender.com
   ```
   (Replace `oilerp-api.onrender.com` with your actual API URL from Step 3)
5. Click "Deploy" and wait

### Step 6: Update API CORS (After Web Deploy)
1. Go back to `oilerp-api` service in Render
2. Go to "Environment"
3. Update `FRONTEND_URL` to: `https://oilerp-web.onrender.com` (replace with actual URL)
4. Click "Redeploy" to apply changes

### Step 7: Test Your Deployment
1. Open your web app: `https://oilerp-web.onrender.com`
2. Sign in with:
   - Email: `admin@oilerp.com`
   - Password: `Admin@123`
3. Change the password immediately

## 🔧 Environment Variables Reference

### API Service (oilerp-api)
| Variable | Required | Description |
|----------|----------|-------------|
| DATABASE_URL | ✓ | PostgreSQL connection string |
| DIRECT_URL | ✓ | PostgreSQL direct connection (for Prisma) |
| FRONTEND_URL | ✓ | Frontend URL for CORS (e.g., https://oilerp-web.onrender.com) |
| JWT_SECRET | ✓ | Auto-generated by Render |
| NODE_ENV | ✓ | Set to `production` |
| NODE_VERSION | ✓ | Set to `22` |
| PORT | | Defaults to 4000 |

### Web Service (oilerp-web)
| Variable | Required | Description |
|----------|----------|-------------|
| API_URL | ✓ | Backend API URL (e.g., https://oilerp-api.onrender.com) |
| NEXT_PUBLIC_API_URL | | Public API URL (defaults to /api for proxying) |
| NODE_ENV | ✓ | Set to `production` |
| NODE_VERSION | ✓ | Set to `22` |

## 📋 Troubleshooting

### "API server unavailable" error
- Check that `API_URL` in web service matches your API service URL
- Verify API service is still running (check Render dashboard)
- Check API service logs in Render

### CORS errors
- Verify `FRONTEND_URL` is set correctly on API service
- Check that web app URL matches `FRONTEND_URL` exactly
- Redeploy API service after changing `FRONTEND_URL`

### Database connection errors
- Verify `DATABASE_URL` and `DIRECT_URL` are identical
- Check that PostgreSQL database is still active (Render free tier doesn't persist)
- Ensure `db:push` and `db:seed` were run

### Build failures
- Check the build logs in Render dashboard
- Verify Node version is 20+
- Ensure all dependencies are in lock files (pnpm-lock.yaml)

## 🔐 Security Recommendations

Before sharing your deployment:
1. Change the demo admin password
2. Set a strong `JWT_SECRET` (Render auto-generates one)
3. Review database access restrictions
4. Consider upgrading from free tier for production
